# The public surface of anvilate's subpackages, one `module.symbol` line per exported
# name, sorted.
#
# `core-public-surface.txt` covers the top-level modules and `analysis-public-surface.txt`
# the analysis library. This is the same contract for everything else — export, packs,
# report, skills, spec, standards, tolerance, units — which had no manifest gate at all
# until 2026-09-09: the core gate keeps `not m.ispkg` and so walked past every package,
# leaving 445 public names growing as a side effect rather than a deliberate diff,
# including all 24 discipline-pack screens and every model they take.
#
# A package's own `__all__` is listed under the package name (`units.Quantity`); a
# module's under the module (`units.quantity.Quantity`). A re-export appears twice
# because it is two public names, and deleting either is a change to the surface.
#
# The gate is in tests/test_contract.py, both directions, with a floor on the number of
# modules walked — a discovery that stops descending would satisfy every line here.
