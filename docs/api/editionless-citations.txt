# Citations that name a normative standard and not its edition (the effectivity debt).
#
# The evidence bundle's whole claim is "these numbers came from these clauses", and a
# clause without an edition weakens it to the point of being unfalsifiable: AISC 360-16
# and -22 both have a Chapter E, ACI 318-14 and -19 both have a §22.8, and they do not
# always say the same thing. "AISC §E3" identifies a paragraph in a book nobody named.
#
# This file records where that is still true, and the gate in tests/test_contract.py
# holds it as a RATCHET: a reference naming a standards body with no edition must either
# name one or be on this list, and a listed reference that has since been versioned must
# be struck off. The list can only shrink.
#
# Textbooks are NOT on this list and are not debt. "Roark Table 8.1" and "Timoshenko
# plate theory" are complete citations as they stand — a textbook is cited by author and
# its printing is not a normative parameter. The gate tells them apart with
# anvilate.standards.effectivity.names_a_standard, which matches a curated list of
# standards bodies rather than anything capitalised.
#
# To pay a line off: add the edition to the reference string, exactly as the standard
# spells it (AISC 360-16, ACI 318-19, EN 1993-1-9:2005), then delete the line. Do NOT add
# a line to silence a failure on a new check — a new check cites an edition.
#
# THIS LIST GREW FROM SIX TO TWENTY-TWO, and none of that is the ratchet slipping. The
# gate used to build its own reference set — the structural pack's entries plus whatever
# the render-truth sample happened to reach — so every other pack's citations were outside
# it. It now reads the session-wide collector in tests/conftest.py, the same one the
# derivation ratchet uses, and cannot be narrower than the library it audits. Sixteen of
# these were editionless the day their pack shipped; the seventeenth reason they were not
# listed is that nothing was looking.
#
# Two additions to STANDARDS_BODIES came with the widening: NEC, because that is the name
# the electrical pack cites the National Electrical Code by, and BS for BS 7910. OSHA's
# 29 CFR 1910.95 is deliberately not a body — a regulation's "edition" is a CFR revision
# date and that is a different fix — and neither is the IES Lighting Handbook, which is
# cited the way Roark is.
#
# To pay a line off: add the edition to the reference string, exactly as the standard
# spells it (AISC 360-16, ACI 318-19, EN 1993-1-9:2005), then delete the line. Do NOT add
# a line to silence a failure on a new check — a new check cites an edition.
#
# The two ASHRAE lines are older than their appearance here. They were carried by the
# ventilation and lighting packs from the day those packs shipped; nothing rendered
# their derivations, so nothing put them in front of this gate until the derivation
# work reached those packs and widened the harvest. They are recorded rather than
# versioned because the edition has to be read off the standard, not guessed: 62.1 and
# 90.1 are both on a three-year cycle and the pack takes its rates from the caller, so
# there is no number in the library that says which book they came out of. The two TMS
# 402 lines arrived the same way and for the same reason.
#
# That this list GREW is not the ratchet slipping. It only ever saw the references the
# structural pack builds plus whatever the render-truth sample happened to reach, so
# every other pack's citations were outside it. Widening the harvest is what found
# these; the list is longer because it is now closer to complete.
# 2026-09-02: three lines struck, and the anchor for each is recorded here because a
# ratchet that shrinks on somebody's recollection is worse than one that does not shrink.
#
#   EN 1993-1-9 and EN 1993-1-9 §8 -> :2005. The only published edition, and the one this
#   library's own WeldDetailCategory records and docs/weld-fatigue-screening.md already
#   declare. The curve anchors in analysis/fatigue.py (N_C = 2M, N_D = 5M, N_L = 100M,
#   m = 3 then 5) and the §8 limit 1.5*f_y are that edition's.
#
#   EN 15978 ... ISO 14040 -> :2011 and :2006. The only edition of each. The A1-A3
#   cradle-to-gate boundary the embodied-carbon screen refuses to mix is EN 15978:2011's
#   module framing, and the declared-scope requirement is ISO 14040:2006's.
#
# EN 1993-1-9 and EN 15978 are in WRITTEN_AGAINST now, which is what makes them answer a
# project's pin rather than only a citation the bundle happens to carry.
#
# The nineteen below are NOT payable by reading this repository. BTH-1's design factors
# (2.00/3.00, 1.20 on fracture) and TMS 402 8.2.4's allowable-stress form are identical
# across their editions, so no constant here identifies one; the fix is to read the
# standard, and guessing would manufacture the confidently-wrong citation this file exists
# to prevent.
