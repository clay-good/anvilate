# Checks that ship without a worked derivation (the derivation-coverage ratchet).
#
# `calculation-report`'s "Derivation metadata is part of the check contract" says CI SHALL
# report the coverage ratio and fail when a newly added check ships without metadata. This
# file is the registry that requirement's scenario refers to, and the gate lives in
# tests/conftest.py.
#
# WHAT A LINE IS. A check is keyed by the clause it cites — the same key the effectivity
# ratchet in docs/api/editionless-citations.txt uses, and the same thing a reviewer reads.
# A clause is COVERED only when every library-produced scorecard entry citing it carries a
# Derivation. One entry short and the clause is not covered: a clause half-derived renders
# a worked formula for some parts and a bare table for others, which reads as though the
# whole thing was derived.
#
# THE TWO SECTIONS ARE NOT INTERCHANGEABLE.
#
#   [lookup]  The check has no formula to render. A process-capability table, a
#             classification, a consistency verdict. It is finished as it stands and will
#             never acquire a derivation.
#
#   [debt]    The check is a formula whose derivation has not been written yet. It is
#             unfinished work, and the list is downward-only.
#
# Filing a debt as a lookup converts an unfinished piece of work into a decision, which is
# a worse silence than the one this registry replaces. The gate enforces the distinction
# mechanically rather than on the honesty of the reason: a clause whose entries carry a
# COMPUTED SAFETY FACTOR cannot be a lookup, because a safety factor is a quotient and a
# quotient is a formula. So a debt cannot be retired by being relabelled.
#
# TO PAY A LINE OFF: attach a Derivation to every entry the check produces, then delete the
# line from [debt]. Do NOT add a line to silence a failure on a new check — a new check
# ships with its derivation. Do NOT move a line to [lookup] to make it stop failing.
#
# Format: one clause per line, then " :: ", then the reason.

[lookup]
ASME BTH-1 §3-1.3 (Design Category) :: the entry is the lifter's identification line — rated load, design load, Category, Service Class. §3-1.3 classifies a device into Category A or B and hands the resulting design factor to every check below it; it computes no margin of its own.
DFM screening estimates (typical finest achievable tolerances) :: the demanded tolerance band is compared with the process floor the capability table records. The table is the whole check; there is no formula between the two numbers.
ASME B30.20 :: a verification-plan item crossed into the characteristic list — a physical proof test with an acceptance criterion and a recorded outcome, not a calculation the library performs.
standards effectivity :: a consistency verdict over the citations a bundle carries — every reference names an edition, and no standard appears at two. No quantity is calculated.

[debt]
AISC 360-16 §L3 :: the serviceability deflection limit δ vs L/n. Derived on 23 of 135 entries; the rest render the limit without the span it came from.
AISI S100 Appendix 1 (Direct Strength Method) :: the DSM capacities from the elastic local, distortional and global buckling loads.
ASCE 7-22 §2.3.1 :: derived where a capacity is screened against the combination; the spec-screening entry that only reports which combination governs re-resolves the set from its name and does not carry the factored sum.
ASME BTH-1 §3-1.4 (Service Class) :: the stress range against the §3-4 allowable for the declared Service Class.
ASME BTH-1 §3-2/§3-3 (allowable stresses) :: the allowables are coefficients on S_y/N_d and S_u/N_d, and the coefficient that applies is the part a reviewer needs to see.
ASME VIII Div 1 Mandatory Appendix 2 (bolted flange connections) :: S_T = Y · M / (t² · B). LooseRingFlangeStress carries the shape factor and both stresses but not the moment, the thickness or B, so the scorecard cannot render the formula without those three being carried on it first.
Aluminum Design Manual 2020 Part I §B.4/§B.5.4/§E.3/§F.4.2 :: the unwelded and heat-affected capacities and the slenderness limits that select between them.
BS 7910 / R6 Option 1 failure assessment diagram :: K_r = K_I/K_mat, L_r = σ_ref/σ_y, and the Option 1 envelope the point is assessed against.
EN 15978 life-cycle modules; ISO 14040 cradle-to-gate boundary :: the embodied carbon is the material mass over the process yield times the cited factor.
EN 1993-1-9 :: the S-N endurance N = 2·10⁶·(Δσ_c/Δσ)^m and the Miner damage sum over the spectrum.
Kirchhoff plate theory (Bessel eigenvalue) :: f = (λ²/2πa²)·√(D/ρh) with λ from the clamped-circular Bessel root.
Kirchhoff plate theory (FD-verified eigenvalue table) :: the same frequency formula with a tabulated eigenvalue; the eigenvalue is an input to the derivation, not a substitute for it.
Kirchhoff plate theory (Navier eigenvalue) :: the simply-supported rectangular plate fundamental frequency.
Kirchhoff plate theory (Navier series) :: the Navier double-sine series for the deflection of a simply-supported plate under pressure.
Kirchhoff plate theory (axisymmetric closed form) :: the clamped and simply-supported circular-plate deflection and stress in closed form.
NDS :: the adjusted design values F'_b, F'_c, F'_v — the reference value times the applicable adjustment factors, which is exactly what a reviewer recomputes.
Roark's Formulas, Table 11.4 :: the table supplies the coefficient; the deflection and stress formulas it feeds are closed form.
Shigley's Mechanical Engineering Design, Marin surface factor k_a = a·S_u^b (surface-finish table, S_u in MPa); screening estimate, not a measured factor :: the citation states the formula; a and b are tabular and S_u is not.
Timoshenko plate theory :: derived for the plate-bending half; the flatness half renders the limit without the deflection formula behind it.
half-sine shock response spectrum :: the SRS amplification as a function of the pulse duration times the natural frequency.
