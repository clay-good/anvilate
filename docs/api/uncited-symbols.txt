# Public analysis symbols that do not yet name a source (the citation debt).
#
# The library's contract is that every check says where its formula comes from. This
# file records where that is not yet true, and the gate in tests/test_contract.py holds
# it as a RATCHET: a symbol missing from this list must be cited, and a symbol ON this
# list that has since been cited must be removed from it. The count can only go down.
#
# To pay a line off: name the source in the function's docstring, or in its module's
# docstring where the whole module follows one text, then delete the line. Do NOT add a
# line to silence a failure on a new function — a new public check cites its source.
#
# A citation is any token in docs/api/citation-authorities.txt appearing in the symbol's
# own docstring or its module's.
