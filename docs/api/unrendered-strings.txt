# Classes that define their own `__str__` and that nothing in the suite ever renders
# (the rendering debt).
#
# An audit once read the `__str__` bodies of this library and found four that dropped the
# field distinguishing two objects from each other. It was an audit and not a gate, so
# renderings went on being added that nothing ever called. `BTH1Allowables` carried five
# allowable stresses, printed three, and called one of the two the standard names "F_t"
# just "F_t" — a reader was shown an unlabelled value and could not tell which, while the
# net-section allowable a lug's net-tension check is judged against was printed nowhere.
#
# The gate in tests/conftest.py holds this as a RATCHET, in the same shape as the
# editionless-citation debt beside it. It fails in three directions: a rendering nothing
# calls that is not on this list, a listed rendering that is now called (strike it off),
# and a listed name that no longer defines a `__str__` at all. The list can only shrink.
#
# THE LIST IS EMPTY. It started at 80: 57 enums fell to a property sweep
# (tests/test_contract.py) and the last 21, which need a constructed object, are read in
# tests/test_unread_renderings.py — which also asserts that this file is still empty, so
# a new unread rendering has to be paid off here rather than parked below.
#
# Paying one off is one line in a test: build the object and read what it prints against
# what it carries. That is how the four were found, and how the beam result's `max_moment`
# and the riveted joint's `joint_strength` were found after them.
