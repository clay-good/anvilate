#
# A module-level `Sources:` line legitimately covers the symbols that were in the module
# when it was written — a module implementing one text cites that text once. It must not
# silently cover a symbol added LATER, or a new check ships uncited into any backfilled
# module and the gate reports coverage the library does not have. So the baseline is
# enumerated here and the gate requires anything not on this list (and not on
# uncited-symbols.txt) to name its source in its OWN docstring.

# not say where its formula came from, and the fix is to say.
