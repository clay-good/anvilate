# Design inverses and the forward check each one inverts.
#
# The contract: an inverse's answer, fed back into its forward check, lands EXACTLY at
# the required margin. Not "better than", not "close to" — an inverse that overshoots is
# a silent cost and one that undershoots is a silent failure. Every pair marked
# round-tripped below has a test in tests/test_design_inverses.py that proves it.
#
# Pairs are hand-verified, never inferred. The library's naming conventions are varied
# enough that automatic pairing resolved only 14 of 156 candidates, and a wrong pairing
# tested automatically would be worse than no test at all.
#
# The gate in tests/test_contract.py requires every public symbol whose name matches the
# inverse-shaped pattern (required_/minimum_/min_/max_/size_ prefix, or _for_/_from_/
# _needed/_to_reach in the name) to appear in this file — either paired and round-tripped,
# or listed as unpaired. A new inverse cannot ship without a decision being recorded.
#
# Format: "<inverse> -> <forward>" for a paired inverse, "<symbol>" alone for one not yet
# paired. Moving a line from the second group to the first means writing its round-trip
# test; that is the whole point of the list.
#
# THE TWO SECTIONS ARE LOAD-BEARING, and were not. Every pair lived under `not yet
# paired` while `round-tripped` was empty, because the gate read `->` anywhere in the
# file and never looked at which heading a line sat under — so the file said, to a
# reader, that nothing here round-trips while fifteen things did. A `->` line under
# `not yet paired`, or a bare name under `round-tripped`, now fails.
#
# AND AN INVERSE MAY NOT BE ITS OWN FORWARD. `fin_array_count_for_resistance` was
# paired with itself, which satisfied the both-halves-are-called gate by naming one
# function twice: the array resistance it inverts was not a public symbol at all, and
# its round-trip test reassembled the formula by hand instead of calling anything.
# `fin_array_thermal_resistance` is that forward now, and the pair is a real one.
